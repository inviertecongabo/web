Términos de Seguridad

Instrucciones obligatorias para conectar Binance

Para que GaboBot pueda ejecutar tus compras, debes crear una conexión API. Sigue estos pasos:

  1. Ve a tu app de Binance y entra a Gestión de API.
  2. Crea una nueva clave y guárdala en un lugar seguro.
  3. Edita las restricciones de la API y marca únicamente "Habilitar Spot & Margin Trading".
  4. Bajo ninguna circunstancia habilites "Permitir Retiros". GaboBot no necesita, ni quiere, permisos para retirar tus fondos.
