Sigue estos pasos o mira el tutorial para habilitar a GaboBot sin comprometer tus fondos.

  • 1. Ve a tu app de Binance y entra a Gestión de API.
  • 2. Crea una nueva API y asegúrate de guardar tanto tu API Key como tu Secret Key en un lugar seguro.
  • 3. Activa la opción Restringir el acceso solo a IP de confianza y pega nuestra dirección IP: 167.172.170.95

  • 4. Edita las restricciones y marca Únicamente "Habilitar lectura" y "Habilitar trading de Margen, Acciones y Spot".
  • 5. NUNCA habilites "Permitir Retiros". GaboBot no necesita, ni quiere, permisos para retirar tus fondos.

¿Cómo funciona?

  1. Pega tu API Key y Secret Key en la sección de Conexión.
  2. Define la cantidad en USDT (mínimo $6) y la frecuencia con la que quieres invertir.
  3. Haz clic en el botón amarillo Guardar Configuración y verifica tu identidad con 2FA.
  4. Sube al inicio de este panel y mueve el interruptor de Estado de Inversión para que quede en Verde (ACTIVO).

Información Importante

Una vez guardada la configuración, recuerda mantener tus USDT en la billetera de Spot de Binance. Si tus fondos están en Futuros, Earn o Fondos, el bot no podrá tomarlos y la compra automática fallará.
