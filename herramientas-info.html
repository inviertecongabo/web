Cómo conectar tu API de forma Segura

No necesitas saber de programación. Solo conectar tu cuenta de Binance de forma restringida para que el bot pueda operar por ti.

1

Genera las claves en Binance

Ve a "Gestión de API" en la configuración de tu cuenta Binance. Haz clic en "Crear API" y asígnale un nombre como "GaboBot". Te darán un API Key y un Secret Key.

2

Restringe los Permisos (Vital)

Al configurar la API, habilita ÚNICAMENTE "Lectura" y "Habilitar Spot & Margin Trading".

NUNCA marques la casilla de retiros. Así tu dinero siempre está a salvo, el bot no puede sacar fondos.

3

Conecta la Herramienta

Pega tus claves (API y Secret) en el panel de configuración de GaboBot en nuestra web. Define tu monto, criptomoneda (ej. BTC) y cada cuánto tiempo quieres comprar (ej. 7 días). ¡Listo!

Preguntas Frecuentes

¿Es seguro conectar mi cuenta de Binance?
Sí, 100% seguro. GaboBot funciona conectando una API Key con permisos estrictamente limitados a lectura y trading spot. Al no habilitar la opción de retiros, el bot jamás podrá sacar tus fondos. Tu dinero siempre se queda en tu cuenta de Binance.
¿El bot requiere que mantenga la plataforma abierta o mi computadora encendida?
No. GaboBot opera de forma 100% automática. Una vez que guardas tu configuración y enciendes el bot desde tu panel de control, nuestros servidores asumen la ejecución automatizada de las órdenes. Por lo tanto, puedes cerrar la página, apagar tu dispositivo o desconectarte de internet sin que esto afecte tus compras programadas.
¿Por qué mis compras a veces se ejecutan por un monto ligeramente menor al configurado?
Esto no es un error ni una limitación del código del bot, sino una regla estricta del mercado de Binance llamada "Tamaño de Lote" (Lot Size). Binance solo permite comprar criptomonedas en bloques fraccionados específicos. Por ejemplo, si configuras el bot para comprar $100, el sistema calcula matemáticamente la cantidad máxima de fracciones que puede comprar sin pasarse de tu límite. Si el bloque exacto más cercano equivale a $99.92, el bot ejecutará esa cantidad para optimizar tu capital. Es muy importante destacar que los centavos restantes (en este caso, los $0.08 sobrantes) no se pierden ni desaparecen; simplemente se quedan guardados de forma segura en tu billetera Spot de Binance.
¿Por qué es obligatorio agregar una dirección IP a mi API de Binance?
Es una medida de seguridad exigida por Binance. Si creas una API Key sin restringirla a una IP de confianza (en este caso, la IP estática de nuestros servidores), Binance la considerará vulnerable y la eliminará automáticamente cada 90 días. Al agregar nuestra IP, garantizas que la conexión de tu bot sea permanente, aumentas drásticamente la seguridad de tu cuenta, y te evitas la molestia de tener que crear una llave nueva cada tres meses.
¿Qué pasa si el mercado cae fuertemente?
GaboBot está diseñado para estrategias DCA. Si el mercado cae, el bot seguirá ejecutando tus compras programadas, lo que te permite acumular más cantidad del activo a precios de descuento, promediando tu precio de entrada a la baja para cuando el mercado se recupere. No se asusta, solo ejecuta.
¿Qué es el DCA (Dollar Cost Averaging)?
Es una estrategia de inversión comprobada que consiste en comprar una cantidad fija de un activo (como Bitcoin) de forma periódica (ej. $50 semanales), sin importar si el precio sube o baja. Esto te evita el estrés de tener que "adivinar" el mercado y promedia tu precio de entrada a largo plazo de forma segura y matemática.
